# Mission: 미니 DBMS로 실제 DBMS 아키텍처 이해하기

## Why
현재 미니 DBMS 코드를 출발점으로 SQL이 어떻게 데이터 읽기·쓰기 작업으로 바뀌는지 이해하고, 실제 DBMS의 구성 요소와 비교해 아키텍처를 설명할 수 있게 된다.

## Success looks like
- SQL 파싱, 계획 수립, 실행, 저장소 접근의 데이터 흐름을 설명한다.
- 프로젝트 함수와 실제 DBMS 구성 요소를 대응시킨다.
- 인덱스, 페이지, 트랜잭션이 이 흐름에서 맡는 역할을 설명한다.

## Constraints
- 현재 저장소의 C 코드와 작은 예제를 중심으로 짧게 학습한다.
- 설명은 쉬운 한국어로 하고, 한 번에 한 개념씩 다룬다.

## Out of scope
- 당장은 DBMS 전체를 구현하거나 운영하는 것.
