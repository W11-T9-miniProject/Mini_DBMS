# DBMS Architecture Resources

## Knowledge

- [Video: B+Tree (B+트리), 자료구조&알고리즘 #10](https://www.youtube.com/watch?v=sXD5lE-B17Q)
  짧은 한국어 개요 영상. B+트리의 구조와 데이터베이스 인덱스에서 쓰는 이유를 처음 복습할 때 사용한다.
- [Lecture: CMU Database Group, Tree Indexes: B+Trees](https://www.youtube.com/watch?v=scUtG_6M_lU)
  약 82분의 대학 강의. 삽입, 노드 분할, 범위 검색을 더 깊게 공부할 때 사용한다.
- [SQLite: Architecture](https://www.sqlite.org/arch.html)
  공식 아키텍처 설명. SQL 컴파일, 가상 머신, B-tree, 페이지 캐시가 연결되는 방식을 확인할 때 사용한다.
- [SQLite: Query Planning](https://www.sqlite.org/queryplanner.html)
  인덱스와 쿼리 계획이 조회 방식을 어떻게 바꾸는지 살펴볼 때 사용한다.
