SQL은 언어,
SQLite는 DBMS

명령의 문법과 그 명령을 실행하는 프로그램은 서로 다른 것입니다.

역할이 다르다

SQL은 관계형 데이터베이스에 명령하는 언어입니다. SELECT, INSERT, CREATE TABLE 같은 문법이 여기에 속합니다.

SQLite는 SQL을 받아 해석하고, 데이터 파일을 읽고 쓰는 DBMS 소프트웨어입니다. 별도의 데이터베이스 서버 프로세스 없이 애플리케이션 안에 라이브러리로 포함해 사용할 수 있습니다.

사람이 SQL을 작성
      ↓
SQLite가 SQL을 파싱·계획·실행
      ↓
데이터베이스 파일에서 결과를 읽거나 변경

같은 SQL, 다른 DBMS

SQLite, PostgreSQL, MySQL은 모두 SQL을 사용하지만, 지원하는 문법이나 자료형, 함수, 관리 방식이 완전히 같지는 않습니다. SQL 표준을 바탕으로 하되 각 제품이 지원 범위와 방언을 갖기 때문입니다.

예를 들어 SQLite는 보통 단일 파일 데이터베이스로 쓰이고, PostgreSQL은 일반적으로 별도 서버 프로세스가 클라이언트 연결을 받아 처리합니다. 두 제품 모두 SQL 문장을 처리하지만 내부 아키텍처와 운영 방식은 다릅니다.

우리 프로젝트는 어디에 있나?

이 프로젝트는 SQL의 일부 문법만 직접 처리하는 작은 DBMS 프로그램입니다. INSERT와 SELECT를 읽고 자체 파일 형식으로 행을 저장합니다. SQLite 라이브러리를 호출하는 프로그램은 아닙니다.

SQL: 공통 언어 계열

이 미니 DBMS:
  SQL 일부를 직접 해석하는 코드 + .schema/.rows 파일

SQLite:
  SQL 처리 엔진 + 자체 파일 형식 + B-tree/페이지 캐시 등

따라서 “SQL을 쓴다”가 “SQLite를 쓴다”는 뜻은 아닙니다.
